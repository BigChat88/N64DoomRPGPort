# input/

Put your **Doom RPG** BREW game archive here, then run `build.cmd` (or
`python app/build_rom.py`).

Accepted:

* `doomrpg.zip` — as the game is commonly distributed: a ZIP that contains
  `doomrpg.bar` (any casing).
* `doomrpg.bar` — the raw BREW asset archive itself.

The build picks the first `*.zip` or `*.bar` in this folder. See the repo
README for what this file is and must contain.

Nothing here is committed (copyrighted game data).
